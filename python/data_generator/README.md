# Генератор синтетичних даних AutoParts

Заповнює PostgreSQL-базу, створену зі `database/schema/01_schema.sql`, довідниками, клієнтами, товарами,
замовленнями з позиціями та поверненнями. Структура БД і SQL-аналітика не змінюються.

## Підготовка
1. `pip install -r requirements.txt` (з кореня проєкту).
2. **Створіть НОВУ порожню БД** (наприклад `autoparts_bi_v2`) і виконайте в ній `database/schema/01_schema.sql`.
   Генератори навмисно відмовляються працювати з непорожніми таблицями — робочу БД вони не чіпають.
3. Скопіюйте `.env.example` у `.env` у цій папці та впишіть свої `DB_*` (файл у `.gitignore`).

## Запуск (з папки `python/data_generator`)
```
python main.py check-connection      # лише перевірка з'єднання
python main.py all                   # seeds -> customers -> products -> orders -> returns -> validate
python main.py all --seed 7 --orders 50000 --end-date 2026-11-01
python main.py orders                # окремий крок (батьківські таблиці вже мають бути заповнені)
python main.py validate              # перевірки якості, лише читання
```
Кожен крок — одна транзакція (помилка = відкат кроку). Перед записом показується цільова БД і запитується
підтвердження (`--yes` для неінтерактивного запуску). Код завершення: 0 успіх, 1 помилки валідації, 2 помилка запуску.

## Параметри (`config.py`, `GEN_*`, опції CLI)
seed=42, history_months=30, customers=2000, products=10000, orders=60000, return_rate=0.035 тощо.
Той самий `seed` + той самий `--end-date` дає ідентичні дані (за замовчуванням end_date = сьогодні).

## Бізнес-правила повернень
Лише для Completed-замовлень, не більше одного повернення на замовлення, 1–3 позиції, повна кількість позиції,
дата повернення пізніша за дату замовлення, `refund_unit_price` — за одиницю з урахуванням знижки позиції.

## Перевірки (`validation.py`)
~56 перевірок: відповідність ERD, обсяги, цілісність, дублікати, дати, ціни/знижки/маржа, повернення,
статуси, реалістичність розподілів. ERROR → код 1; WARN/INFO — для огляду.

## Тести
`pytest tests` — юніт-тести без БД. Перевірка згенерованої БД: `RUN_DB_TESTS=1 pytest tests/test_data_quality.py`.
